# Neko SDK prerequisite

Get `l4n_plugin.h` from the official [NekoShaders & L4N distribution](https://steamcommunity.com/sharedfiles/filedetails/?id=3558049615) and place it at `sdk/l4n_plugin.h`. Use the IL4NPlugin V2 header compatible with Left4Neko 2.51.0. You can also set `L4N_SDK_DIR` to the directory containing that header before running `build.cmd`.

The header and Neko runtime are distributed by their author and are subject to the author's terms.
